# TechDent Backend

Backend API for the TechDent platform.

## Features

- JWT Authentication
- User Management
- REST API
- Docker Support

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Docker

## Requirements

- Node.js
- MongoDB
- Docker (Optional)

## Installation

```bash
npm install
```

```bash
cp .env.example .env
```

Configure your environment variables.

```bash
npm run dev
```

## Docker

```bash
docker compose up --build
```
